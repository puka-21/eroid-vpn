# EROID VPN для Windows (PC)

Высокопроизводительный VPN-клиент для Windows, написанный на **Rust** с графическим интерфейсом на **egui**.

## Особенности
- Встроенные бинарники Sing-Box 1.14 и WinTUN (распаковываются автоматически).
- Поддержка системного прокси и TUN-режима.
- Автоматический запрос прав администратора (необходим для создания интерфейса WinTUN).
- Мониторинг задержки (ping) для каждого узла.
- Автоматическое отключение системного прокси при завершении работы или сбое.

## Сборка из исходников

1. Установите [Rust](https://rustup.rs/):
   ```cmd
   rustup default stable-x86_64-pc-windows-msvc
   ```
2. Соберите релизную версию:
   ```cmd
   cargo build --release
   ```
   Либо запустите скрипт `build.bat`.

3. Исполняемый файл появится в `target/release/eroid-vpn.exe`.
   Для запуска с поддержкой TUN запускайте от имени Администратора (скрипт `run_admin.bat`).
