# EROID VPN — кастомный клиент на ядре Sing-Box 1.14

> **Ищу разработчиков, которые помогут портировать клиент на Android.**

### Ключевые возможности

* **Все современные протоколы:** VLESS Reality, WireGuard, AmneziaWG, Trojan — стабильная работа на максимальной скорости.
* **Обход ограничений:** маскировка под INCY / HAPP и встроенная подмена HWID для обхода лимита «1 устройство».
* **Умная маршрутизация:** Госуслуги, Сбер, Т-Банк и сайты РФ открываются напрямую, а заблокированные ресурсы (Instagram, YouTube и др.) — через туннель.
* **Встроенный AdBlock:** прямо из коробки блокирует баннерную рекламу и трекеры.
* **Минималистичный дизайн:** 5 тёмных тем (OLED, Cyberpunk, Nordic и др.), одна большая кнопка подключения и ничего лишнего.
