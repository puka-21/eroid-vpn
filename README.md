# EROID VPN — наш кастомный клиент на ядре Sing-Box 1.14:
    Ищу людей которые смогут портировать на андройд
Все протоколы: VLESS Reality, WireGuard, AmneziaWG, Trojan (летает на максимальной скорости).
Обход ограничений: маскируется под INCY / HAPP и умеет подменять HWID, чтобы обходить лимит «1 устройство».
Умный доступ: Госуслуги, Сбер, Т-Банк и сайты РФ открываются напрямую, а запрещёнка (Инста, Ютуб и т.д.) — через туннель.
AdBlock: сразу из коробки режет всю баннерную рекламу и трекеры.
Литой дизайн: 5 топовых тёмных тем (OLED, Cyberpunk, Nordic), одна большая кнопка подключения, ничего лишнего.
